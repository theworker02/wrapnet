# wrapnet

Wrap structured JSON net payloads without a heavyweight toolkit.

**Site:** https://theworker02.github.io/wrapnet/

## Install / run

```bash
git clone https://github.com/theworker02/wrapnet.git
cd wrapnet
node src/cli.js
node --test
```
